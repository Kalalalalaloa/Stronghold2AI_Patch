# Stronghold 2 AI Overhaul v4.5 Test Plan / Testplan

1. Restore an older castle profile first, then install v4.5 through `Launcher.cmd`.
2. Start with `Brutal` on a large/open map and compare Barclay, Edwin, and Lady Seren against a previous or vanilla run.
3. At 10, 20, and 40 minutes record granaries/food buildings, housing, markets, weapon workshops, armouries, barracks, engineers' guilds, siege camps, and stables.
4. Confirm each named lord still uses a visually distinct castle and that gates/towers remain accessible from the intended courtyard.
5. Repeat on one cramped map with `Balanced`. Report incomplete walls, outward-facing access, red buildings, blocked workers, or reduced defenders.
6. Combine v4.5 castles with optional DLL v0.8 for the full test. Use the same difficulty first; on cramped maps combine Balanced castles with Brutal/Overlord runtime pressure.
7. After testing, use `Backup restore` and verify the launcher reports the original files again.
